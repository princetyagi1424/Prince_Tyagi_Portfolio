# Prince Tyagi — Portfolio

**Live:** [prince-tyagi-portfolio.pages.dev](https://prince-tyagi-portfolio.pages.dev/)

Personal portfolio of **Prince Tyagi**, B.Tech Computer Science Engineering (AI & Data Science) student at **GLA University, Mathura** (Class of 2029).

## Highlights

- Responsive design: mobile, tablet, laptop, desktop
- Light / dark theme with sun–moon toggle (preference saved)
- Cinematic 3D intro + particle name animation
- Live LeetCode stats + contribution heatmap (tablet & up)
- Selected projects: **Hand Gesture Box Creator**, **GLA Campus Navigator**
- Certificates, education, contact form, resume download
- Accessibility: skip link, focus states, reduced-motion support

## Stack

React · TypeScript · Vite · Tailwind CSS · Three.js / React Three Fiber · Cloudflare Pages

## Local development

```bash
cd artifacts/prince-tyagi-portfolio
pnpm install
pnpm dev
```

```bash
pnpm typecheck
pnpm build
```

## Deploy (Cloudflare Pages)

```bash
pnpm build
npx wrangler pages deploy dist/public --project-name=prince-tyagi-portfolio
```
